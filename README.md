📉 Customer Churn & Retention Analytics Dashboard

An end-to-end business intelligence solution developed in Power BI to analyze customer attrition, uncover behavioral patterns, and empower data-driven retention strategies.

---

##  Executive Summary
Customer churn is one of the most critical challenges for subscription-based businesses. This project delivers a comprehensive, interactive Power BI dashboard designed to monitor subscription trends, identify high-risk customer segments, and provide actionable insights to minimize churn and maximize customer lifetime value (LTV).

---

##  Key Business Objectives
* **Identify Attrition Drivers:** Pinpoint correlations between contract types, payment methods, and customer churn rates.
* **Monitor Core KPIs:** Track high-level metrics including total active customers, overall churn percentage, and average revenue per user (ARPU).
* **Segment Analysis:** Evaluate customer behavior across demographics, usage frequency, and tenure brackets.

---

## 🚀 Key Features & Dashboard Highlights
* **Dynamic KPI Summary Cards:** Instant visibility into total customer count, churned users, and retention rates.
* **Advanced Slicers & Filters:** Seamlessly slice data by contract length (Monthly, Quarterly, Annual), subscription tiers, and geographic regions.
* **Visual Data Storytelling:** Clean layout featuring custom-styled donut charts, clustered column charts, and trend lines.
* **Interactive Tooltips:** Deep-dive metrics accessible directly on hover for granular analysis.

---

## 🛠️ Technical Stack & Tools Used
* **Data Visualization:** Power BI Desktop (Custom themes, layout structuring, bookmarks, and UI/UX design)
* **Data Modeling & Transformation:** Power Query (Data cleaning, handling missing values, and relational schema mapping)
* **Analytics & Metrics:** DAX (Data Analysis Expressions) for calculated columns and dynamic measures
* **Version Control:** Git & GitHub for professional code and asset management
